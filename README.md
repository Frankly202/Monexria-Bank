# Monexria Bank - Innovative Banking Solution

A comprehensive banking application with proven impact, loan options, savings accounts, and investment opportunities.

## 🏗️ Project Structure

```
Monexria-Bank/
├── backend/              # Node.js/Express API
├── frontend/             # React Web Application
├── mobile/               # Flutter Mobile Application
└── docs/                 # Documentation
```

## 🚀 Features

✅ User Authentication & Account Management
✅ Transactions (Deposits, Withdrawals, Transfers)
✅ Balance Tracking
✅ Transaction History
✅ Admin Dashboard
✅ Multi-Currency Support
✅ Security Features (JWT, Encryption)
✅ Real-time Notifications

## 📋 Tech Stack

### Backend
- **Node.js** 18+
- **Express.js** - Web framework
- **PostgreSQL** - Database
- **JWT** - Authentication
- **Bcrypt** - Password hashing
- **Socket.io** - Real-time updates

### Frontend
- **React** 18+
- **Redux** - State management
- **Axios** - HTTP client
- **Tailwind CSS** - Styling
- **Chart.js** - Analytics

### Mobile
- **Flutter** 3.0+
- **Dart** - Programming language
- **Firebase** - Push notifications
- **Hive** - Local storage

## 🛠️ Getting Started

### Backend Setup
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```

### Mobile Setup
```bash
cd mobile
flutter pub get
flutter run
```
